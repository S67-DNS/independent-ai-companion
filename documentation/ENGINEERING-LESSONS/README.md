# 真实工程经验与失败教训索引

我们不隐瞒失败。以下四篇记录的都是**实际发生过**、并且改变了实现或验收口径的问题。

| 文档 | 主题 | 一句话结论 |
|---|---|---|
| `EL-01-substring-path-bypass.md` | 用子串匹配做路径安全判定 | fail-open 的默认拒绝不了相对路径、相似目录与目录联接；必须改为解析后比较 |
| `EL-02-tool-surface-evidence.md` | 静态读配置证明不了工具面遮蔽 | 证据必须来自模型实际收到的请求体，且要先排除会话标题生成等非业务请求 |
| `EL-03-test-harness-port-collision.md` | 测试脚手架误触被占用端口 | 根因是「测试默认可连真实端点」；靠启动强制、求值前拦截与对抗计数解决 |
| `EL-04-mock-vs-real.md` | 证据口径混淆 | 把 Mock、静态检查、历史记录写成「真实运行」，是比编造数据更常见的失真 |

**共同主线**：四次修正都不是加功能，而是**收紧判据**——把「看起来对」换成「能被反例推翻但仍成立」。
