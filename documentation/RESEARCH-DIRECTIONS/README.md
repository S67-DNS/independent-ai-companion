# 尚未解决的问题索引

`ROADMAP.md` 给出八个方向的全景与优先级；本目录对其中四个最关键的做**问题级展开**，每篇都写明「已实现的基础」与「仍然缺失」，并给出可证伪的实验设计。

| 文档 | 核心问题 | 最关键的一句话 |
|---|---|---|
| `RD-01-identity-continuity.md` | 独立于模型的长期身份连续性 | 已实现「身份文本由核心持有并能被注入」，不等于已实现「独立于模型的身份连续」 |
| `RD-02-memory-subject-isolation.md` | 多层记忆的主体隔离与可信注入 | 可以访问记忆、可以把文本送进请求体、可信地注入属于正确主体的记忆，是三件事 |
| `RD-03-unified-runtime-interface.md` | 可替换模型与 Runtime 的统一接口 | 只有「重启同一个」的证据，「更换」从未执行，这是最需要被外部复核的假设 |
| `RD-04-long-running-safety.md` | 长期运行中的安全、权限与可恢复性 | 已验证若干机制的短周期行为，不是长期压力下的收敛性 |

**共同的优先级判断**：先补证据，再谈可替换性，最后才谈自主性。在注入证据去自证、反向用例、跨进程双写与结果未知状态重放这几项补齐之前，新增功能只会扩大未验证面。
