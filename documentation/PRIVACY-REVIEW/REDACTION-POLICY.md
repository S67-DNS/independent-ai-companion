# 脱敏与公开范围说明（面向读者）

> 本页说明这套资料**为什么这样写**，以及哪些内容被主动排除。它本身不包含任何被排除的信息。

## 1. 基本原则

这套资料讨论的是技术问题，不是某个具体主体。因此所有涉及主体、使用者、渠道与模型提供方的名称，都统一替换为占位符：

| 占位符 | 含义 |
|---|---|
| `[CORE_ENTITY]` | AI 核心主体 |
| `[PROJECT_NAME]` | 项目名称 |
| `[OWNER]` | 使用者或管理者 |
| `[MODEL_PROVIDER]` | 模型提供方 |
| `[COMMUNICATION_CHANNEL]` | 通信渠道 |

具体产品名、运行时名与平台名也抽象为通用术语。示例全部是抽象示例，**不来自任何真实对话、真实经历或真实人物设定**。

## 2. 主动排除的内容类别

以下类别不进入公开资料，也不作为「案例」出现：

1. 非公开的记忆条目、个人经历记录、消息原文与设定文本；
2. 任何内部名称、称谓及其变体、缩写、组合与可识别写法；
3. 使用者的个人资料、账号信息、联系方式与私人经历；
4. 真实账号、用户 ID、群号、手机号、服务器地址与本机路径；
5. 密钥、令牌、Cookie、密码与数据库连接凭据；
6. 正式环境数据库、全局记忆数据库、原始消息记录与独立记忆备份；
7. 原始故事、视觉素材、训练数据及未经许可的素材；
8. 含私人信息的截图、日志、调试记录与测试样本；
9. 任何可通过时间、账号、关系与事件组合还原私人主体的资料。

判断规则很简单：**如果无法确定某份资料是否含有隐私，就默认不公开**，而不是尝试脱敏后发布。含身份线索的原始报告被整份排除，不做逐句替换。

## 3. 脱敏覆盖范围

审核不只扫描 Markdown 正文，还覆盖：

- 文件名与目录名；
- Markdown、代码、配置文件、示例配置；
- 注释、字符串常量与测试数据；
- 提交历史与分支信息（本套候选不含版本库）；
- 日志、异常堆栈与运行报告；
- 图片 EXIF 与其他元数据（本套候选不含图片或二进制文件）；
- 数据库导出文件（本套候选不含任何数据库或导出文件）；
- 文件内部引用的绝对路径；
- 可识别主体身份的组合信息。

## 4. 来源链：原件不动，副本整理

公开候选不是从原始项目目录直接复制后发布的：

```
原始资料（只读）
  → 独立工作副本（内部，标记禁止外流）
  → 人工重写的脱敏技术事实摘录
  → 公开候选初稿（全部重新组织，不引用原文段落）
  → 交付候选（仅此目录可进入审核）
```

原始资料在整理前后做了文件清单与 SHA-256 对比，确认未发生变化。公开候选不引用、不粘贴、不转述任何原始报告的原文段落、文件名、路径、账号或日志行。

## 5. 成果表述的自我约束

- 不把 Mock 测试写成真实运行验证；
- 不把局部链路成功写成完整闭环成功；
- 不把历史测试记录写成本次集成通过；
- 不把愿景写成已经实现的能力；
- 明确列出「未执行」的项目，而不是省略它们。

## 6. 当前状态

本仓库为已完成公开范围整理的技术探索归档。详细的机器扫描结果、隐私排除清单与人工复核记录属于内部审核材料，不随本仓库公开；未公开文件的数量、分类与排除原因见仓库根目录的 `PUBLIC-ASSET-EXCLUSIONS.md`。
