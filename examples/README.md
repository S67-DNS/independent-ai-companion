# 通用示例配置

本目录只放**不含真实值**的示例配置，用于说明配置结构与启动方式。

| 文件 | 说明 |
|---|---|
| `config.example.json` | 主配置结构示例：网关地址、运行参数、preset、权限开关等 |
| `local-window.config.example.json` | 本地窗口 UI 的中性配置：`transport: mock`、独立数据目录、无密钥 |

## 使用约束

- 所有地址均为通用回环示例值或占位符，**不是真实部署信息**。
- 所有 `apiKey` / `token` 字段为空或明显占位串；**不含任何真实凭据**。
- 所有账号、用户 ID、群号均为 8 位示例 ID，不是真实账号。
- 路径使用相对路径或 `<WORKSPACE>/` 占位，不含本机绝对路径。
- 示例中的 `baseURL` 指向 `example.invalid` 一类保留域或本地回环，不会发起真实外部请求。

## 不得做的事

- 不得把示例配置直接用于任何正式环境。
- 不得用示例值反推真实部署拓扑。
- 启动本地窗口服务时，请通过环境变量把数据目录指向隔离目录，并使用 `mock` 通道。
