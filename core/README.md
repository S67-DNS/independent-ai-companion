# 核心 sidecar 自研源码

**来源**：自主开发的独立核心 sidecar 副本，经全链路脱敏后纳入候选。
**形态**：Node.js ESM（`.mjs`），入口见 `package.json` 的 `start` / `check`。
**状态**：`已测试（语法级）`，**未在本包内独立运行**——它需要宿主 Agent Runtime 与消息网关。

## 模块清单与状态

| 子目录 | 职责 | 状态 |
|---|---|---|
| `app/host/` | 宿主进程、出站护栏、生产环境误触防护 | 已实现，未独立运行 |
| `app/gateway/` | 消息网关适配与入站事件 | 已实现，未独立运行 |
| `app/adapters/` | 运行时提示、DSH 适配、正式网关策略 | 已实现，未独立运行 |
| `app/bridge/` | 会话绑定、派发与投递队列 | 已实现，未独立运行 |
| `app/lifecycle/` | 生命周期、待命与唤醒状态 | 已实现，未独立运行 |
| `app/security/` | 出站策略与权限判定 | 已实现，未独立运行 |
| `app/core/` | 数据模型、迁移与候选实现 | 已测试（语法级） |
| `app/config/` | 配置装载与默认值 | 已实现 |
| `app/shared/` | 共享工具 | 已实现 |

**分类口径**：`已运行` / `已测试` / `未集成` / `实验性` / `废弃`。本目录内**没有**被判定为「已运行」或「废弃」的模块；全部为「已实现、经语法检查、未在本包内独立运行」。

## 依赖与集成条件

- 运行时依赖：`js-yaml`、`argparse`（见 `package.json`），以及 `node:sqlite`（Node.js 22+）。
- 集成条件：需要宿主 Agent Runtime、消息网关、独立数据库与独立配置；**不得与任何正式运行环境共享可写数据**。
- 本包不含 `node_modules`，不含任何真实配置、密钥、账号或部署地址。

所有专属名称、账号、本机绝对路径、内部标识、个人联系方式、日期戳均已在独立副本中替换或排除；源码通过 `node --check` 110/110。详见 `documentation/PRIVACY-REVIEW/`。
