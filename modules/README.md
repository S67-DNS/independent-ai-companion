# 自主开发模块（A 类）

| 模块 | 内容 | 状态 |
|---|---|---|
| `state-core/` | 记忆来源与 CAS、写入闸门、写入所有权/栅栏、投递队列、注入过滤、preset 注册、身份读取、SQLite 迁移、权威路径写入守卫 | **已测试**：90/92 用例通过（隔离副本） |
| `bridge-utils/` | 通用桥接工具：权限判定、安全请求、进程锁、历史检索、记忆交接与生命周期、格式归一、令牌账本、等待契约、健康检查、配置读取、出站策略、状态 ACL 等 | 已实现、语法检查通过；**未独立运行**（依赖宿主服务） |
| `ui/local-window/` | 本地窗口 UI 与服务：`public/`、`lib/`、测试与示例配置（第三方内嵌单文件应用已排除） | **已运行**：mock 通道下页面、资源、接口与交互全部验证通过 |
| `ui/console.html` | 控制台页面 | 已脱敏；**未独立运行**（依赖宿主接口） |

## 分类口径

- **已运行**：`ui/local-window/`（隔离端口 + mock 通道，验证后已停止）。
- **已测试**：`state-core/`（单元与机制测试，2 个上游既有的多进程并发用例失败）。
- **未集成**：`bridge-utils/`、`ui/console.html` 需要宿主运行时才能运行。
- **实验性**：无。本包不收录无法判断用途的实验代码。
- **废弃**：无。`legacy/` 下的兼容钩子保留并标注，未删除，但不作为推荐入口。

## 目录关系说明

`state-core/tests/` 中的测试按上游原始相对路径引用 `../src/candidate/`、`../migrations/`、`../plugins/`。为让测试可直接运行，**未把这些测试移到顶层 `tests/`**；顶层 `tests/` 只放复现说明。

`state-core/` 的目录名不含「memory」字样，因为权威路径写入守卫会把路径中含该关键字的普通目录误判为权威目录——这是整理过程中实测发现并规避的问题，不是功能改动。

## 已排除的模块

含角色设定、私人素材、语音/形象资产、真实凭据、生产状态或内部运行报告的模块与目录，按「不确定即排除」原则未纳入本包。它们不属于「通用功能模块」。
